# Design-and-Verification-of-an-Enhanced-DMA-Controller-Using-Verilog-HDL
Design and Verification of an Enhanced DMA Controller using Verilog HDL and Xilinx Vivado, targeting the Artix-7 FPGA (xc7a325t-1). Features include FIFO buffering, burst transfers, error detection, interrupt generation, and status monitoring, verified through RTL simulation and FPGA implementation.
